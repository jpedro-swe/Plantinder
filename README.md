Uma plataforma web criada para conectar pessoas que desejam doar plantas com quem busca adotar uma nova mudinha. A proposta do projeto é facilitar a troca de plantas de forma simples, visual e responsável, promovendo uma experiência agradável e intuitiva.

## 🌐 Acesso ao site

Você pode acessar a aplicação em produção através do Vercel:

https://plantinderjhd.vercel.app/

## ✨ Sobre o projeto

O PlantTinder foi pensado como uma solução digital para promover a adoção responsável de plantas. A ideia central é unir doadores e adotantes em uma interface moderna, inspirada em sistemas de matching, onde é possível encontrar plantas próximas, avaliar opções e combinar a entrega com facilidade.

O projeto foi desenvolvido como parte de um trabalho acadêmico de Análise e Projeto de Sistemas, com foco em usabilidade, requisitos funcionais e proposta de solução tecnológica.

## 🚀 Funcionalidades

- Cadastro de usuário com dados e preferências
- Publicação de plantas disponíveis para adoção
- Busca e filtros por espécie, localização e características
- Solicitação de adoção entre usuários
- Comunicação por chat para combinar entrega/retirada
- Avaliação da experiência após a adoção
- Interface responsiva para desktop e mobile
- Design moderno e visualmente atrativo

## ▶️ Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/jpedro-swe/Plantinder.git
```

2. Entre na pasta do projeto:

```bash
cd Plantinder
```

3. Inicie um servidor local:

```bash
python3 -m http.server 8000
```

4. Abra no navegador:

```bash
http://localhost:8000
```
