# PlantTinder

Uma plataforma web para conectar pessoas que desejam doar plantas com quem quer adotar uma nova mudinha. O projeto foi pensado como uma experiência visual e interativa, inspirada em interfaces de matching, com foco em adoção responsável e facilidade de uso.

## 🌱 Visão geral

A PlantTinder ajuda a simplificar o processo de encontrar uma planta ideal para o seu espaço, avaliando preferências, proximidade e perfil do doador. A interface foi desenvolvida para ser amigável, moderna e responsiva, funcionando bem em desktop e mobile.

## 🚀 Acesso ao site

Você pode acessar a versão publicada no Vercel aqui:

https://plantinderjhd.vercel.app/

## ✨ Funcionalidades

- Cadastro de usuário com dados básicos e preferências
- Anúncio de plantas disponíveis para adoção
- Busca e filtros por espécie, tamanho e localização
- Solicitação de adoção com comunicação entre usuários
- Chat para combinar entrega ou retirada da planta
- Avaliação da experiência após a adoção
- Design responsivo e visual moderno

## ▶️ Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/jpedro-swe/Plantinder.git
```

2. Acesse a pasta do projeto:

```bash
cd Plantinder
```

3. Inicie um servidor local:

```bash
python3 -m http.server 8000
```

4. Abra no navegador:

```text
http://localhost:8000
```
